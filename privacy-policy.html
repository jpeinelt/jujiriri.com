Types of Data Collected

Personal Data may be freely provided by the User, or collected automatically when using this Application. Any use of Trackers by this Application or by third-party services serves the purpose of providing the Service and delivering relevant advertising as described below.

Purposes of Processing

Data is collected to allow the Owner to:

  • Detect malicious or fraudulent activity
  • Display content from external platforms (e.g. Google Fonts)

Detailed Information on Third-Party Services

Google AdMob (Google Ireland Limited)

This Application uses Google AdMob to display banner advertisements to non-premium users. AdMob may collect and process the following data to serve personalized or non-personalized ads:

  • Device Identifiers (e.g. IDFA on iOS, if the user grants App Tracking Transparency permission)
  • Coarse Location (derived from IP address — not GPS)
  • Usage Data (app interactions, ad impressions, clicks)
  • Advertising Data (ad performance and engagement)

Personalized ads are only served if the user has given explicit consent via the in-app consent form (powered by Google's User Messaging Platform) and, on iOS, granted App Tracking Transparency (ATT) permission. Without consent, only non-personalized ads are shown.

Personal Data processed: Device Identifiers; Usage Data; Coarse Location; Advertising Data; Trackers.
Place of processing: Ireland (and other countries where Google operates) — Google Privacy Policy, AdMob Partner Policies.
Legal basis (GDPR): Consent (Art. 6(1)(a) GDPR).

Google Fonts (Google Ireland Limited)

Google Fonts is a typeface visualization service provided by Google Ireland Limited that allows this Application to incorporate content of this kind on its pages.

Personal Data processed: Trackers; Usage Data.
Place of processing: Ireland — Privacy Policy.

App Tracking Transparency (iOS)

On iOS, this Application requests permission via Apple's App Tracking Transparency framework before accessing the device's advertising identifier (IDFA). Users may deny this permission at any time in iOS Settings → Privacy & Security → Tracking. If permission is denied, the Application will not use the IDFA for tracking.
